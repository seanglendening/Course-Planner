HARVARD UNIFIED COURSE PLANNER — DEPLOYABLE CLASS PACKAGE

Open index.html directly to test the planner. It has no server, login, database,
analytics, or external JavaScript dependency.

CATALOG LIMITATION
This class demonstration contains seven saved HKS sample records. It does not
search the complete Harvard, MIT, or Fletcher catalogs and has no live timetable,
seat, eligibility, HarvardKey, or registration connection. The interface states
this prominently and does not invent results for schools without loaded records.

SIMPLE PUBLICATION OPTIONS
1. GitHub Pages: create a public repository, upload index.html, open Settings >
   Pages, publish from the main branch/root, then use the generated URL.
2. Netlify Drop: drag this entire folder onto Netlify Drop while signed in.
3. Any static web host: upload index.html as the root document.

Before submitting, open the resulting URL in a private/incognito window and run
through all six steps. A local file path or ChatGPT attachment is not a public URL.
